2. Task Objective

Goal: Train a multi-agent RL model on the MPE simple_spread environment.

  • Agents: 3 cooperative agents
  • Landmarks: 3 targets for agents to cover
  • Observations: Continuous 18-dimensional vector per agent
  • Actions: Discrete (5): NOOP, UP, DOWN, LEFT, RIGHT
  • Rewards: Dense reward; negative distance to landmarks
  • Training Requirement: Maximize coverage efficiency while avoiding collisions

3. Algorithm Choice

QMIX – Value-based Multi-Agent Reinforcement Learning

  • Centralized training, decentralized execution (CTDE)
  • Individual agent Q-networks combined via mixing network
  • Monotonic constraint ensures each agent’s action contributes positively to global Q-value
  • Decouples training (centralized) and execution (independent per agent)

4. Model Architecture

Agent Q-Network

  • Input: agent observation (18-dim)
  • Architecture: MLP, 2 hidden layers, 64 units each, ReLU
  • Output: Q-values for 5 discrete actions

Mixing Network

  • Input: individual Q-values + global state
  • Hypernetwork produces weights conditioned on global state
  • Output: single scalar Q_total

Replay Buffer

  • Stores observations, actions, rewards, next observations, done flags, global state
  • Off-policy training sampled in minibatches

5. Training Configuration

Hyperparameter Value
Optimizer Adam
Learning rate 1e-3
Batch size 32
Discount γ 0.95
Replay buffer 50,000 transitions
Target update frequency 200 steps
ε-greedy start → end 1.0 → 0.05 (linear decay)
ε-decay steps 10,000
Network size 64 / 64 MLP

Training Notes:

  • Separate training vs evaluation:
    • Training: stochastic policy (ε-greedy)
    • Evaluation: deterministic (argmax Q)
  • Always evaluate deterministically to avoid false positives

6. Evaluation Plan

  • Report:

    • Episode length
    • Landmark coverage (min/avg distance)
    • Agent collisions
  • Compare against baseline random agents to quantify learning
